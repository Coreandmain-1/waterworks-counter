# Waterworks Counter
Mobile-first Ford brass counter assistant.

Current MVP recognizes corp stops, curb stops and couplers plus common Ford connection/size codes. It accepts a request through the web UI or the `?q=` URL parameter so an iPhone Shortcut can pass dictated text into the app.

Important: current dataset contains coding logic, not a complete verified Ford catalog. Exact catalog numbers should not be represented as verified until official catalog data is loaded.
